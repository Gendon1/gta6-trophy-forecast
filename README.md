Forecasts how many GTA VI players earn each trophy in week one: for every trophy it forecasts five quantiles (5%, 25%, 50%, 75%, 95%) of its earn rate on Exophase at 2026-11-26, from the reads in the case file. The model fits each trophy's logit-rate trend over its history and, when the history is flat, applies a per-trophy refresh-drift (rare trophies fall further as new players dilute the tracked pool) with a spread that widens with the horizon.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
